How the calculator thinks
Each anvil operation adds a prior-work penalty. The calculator searches possible merge trees and keeps the cheapest candidates while respecting the 39-level anvil cap. Select the enchantment level you already have, then let the machine do the combinatorial suffering.

Which objective should I use?
Least XP / Levels minimizes the total XP cost represented by the calculated merge sequence. Least prior work prioritizes lower accumulated anvil work penalties. In practice, XP is usually the useful default.
